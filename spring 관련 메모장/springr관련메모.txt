tomcoat연결 방법
좌측하단 Servers 탭에서 빈 곳을 마우스 우클릭 >  New > Server 선택
Apache > Tomcat vX.X (설치한 버전)를 선택하고 Next를 누릅니다
Tomcat installation directory에서 톰캣이 설치된 폴더 경로를 지정하고 Finish를 누릅니다
서버 목록에 톰캣이 생기면 우클릭 후 Add and Remove...를 눌러 연결할 프로젝트를 오른쪽(Configured)으로 이동시키고 Finish를 누릅니다
상단의 재생 버튼(Start)을 눌러 서버를 실행합니다
